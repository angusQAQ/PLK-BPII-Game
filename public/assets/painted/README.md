# 手繪素材

製作順序：使用者參考圖 → 人類角色母版 → 分層素材圖片 → 透明輪廓與接合點校準 → 遊戲組合 → 30 fps 圖片幀。

所有素材使用影像生成工具，以上傳參考圖及母版為參考製作。髮型及身體圖集因相鄰素材靠近而重新生成過；PNG 原圖保持完整，實際遊戲依 `manifest.json` 內的來源範圍、透明輪廓與接合點組合，避免把旁邊的素材畫入角色。

`clipRuns` 是圖集繪製時使用的透明輪廓，每項記錄 `[x, y, width]` 的一像素高可見區域。它只用於裁切原始圖片，不畫出新的髮型或服裝。`mount` 保存髮型的頭部接點及顯示比例；`neck` 保存身體的頸部接點。

原始 PNG 的 SHA-256 存在 manifest；變裝和彩帶輸出也保存手繪特效圖集的 SHA-256。重新製作特效輸出時執行 `npm run assets`。遊戲中的變裝圖片幀及完成彩帶皆為 30 fps。

校服與體育服使用後續上傳的實物照片重繪，`uniforms.png` 順序為男生校服、女生校服、男生體育服、女生體育服；舊圖集中的示意校服／運動服不再被角色渲染器使用。

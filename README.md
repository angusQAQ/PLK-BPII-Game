# 玩偶小工房

給小學二年級學生在電子白板操作的外貌描寫遊戲。繁體中文介面、觸控詞卡、人類 Q 版玩偶。這是供審閱的網站版本；依使用者要求，**尚未製作單一 HTML 匯出檔案，也沒有下載按鈕**。

## 啟動網站

需要 Node.js 20 或更新版本，沒有網站執行依賴，無需 npm install。

```sh
cd /workspace/PLK-BPII-Game
npm run dev
```

伺服器預設監聽 3000 埠，可用 PORT 環境變數更改。瀏覽器須能連線到執行伺服器的同一部機器或使用平台支援的埠轉發；雲端機器的 localhost 並不是使用者電腦的 localhost。

## 已實作的玩法

主頁 → 性別 → 頭髮 → 眼睛 → 鼻子 → 嘴巴 → 臉 → 衣服 → 完成總結 → 下一個製作。

- 每步單選，可點選詞卡，或用滑鼠、觸控白板將詞卡拖到頭部／身體。放下後自動套用校準好的五官及頸部接點，不使用放手座標定位素材；按「製作」才進入下一步。
- 開始時沒有頭髮、眼睛、鼻子或嘴巴，穿白色短袖 T 恤及短褲。
- 男生：校服、體育服、西裝；女生：校服、體育服、長裙。兩者各有不同的服裝設計及站姿，不加入性徵。
- 男生提供黑色、棕色、短短及捲曲四張髮型詞卡；女生另有長長的頭髮。女生短髮是帶髮夾的耳下短髮；長髮、短髮及捲髮預設黑色。
- 上一步保留所有選擇；重新開始／下一個製作從性別選擇重新開始；隨時可回主頁。
- 總結包括五個外貌部位及衣服，代名詞按性別顯示。他／她有……。他／她平日喜歡穿……。
- 自由創作，沒有標準答案、計分或計時。只有變裝音效，沒有背景音樂或其他操作音效。

## 圖像及動畫

先依使用者提供的兩張參考圖生成角色母版，再生成透明圖片素材，最後才接入遊戲。美術採用暖色手繪厚塗、水彩紋理、細棕色輪廓、布料細節及日系 Q 版人類比例。

`public/assets/painted/` 包含母版及九張正式圖集，共 59 個分層素材：8 款身體／服裝、4 款臉形、10 款髮型、6 對眼睛、4 款鼻子、2 款嘴巴、12 個特效元素、4 款介面底圖及 9 款獨立瀏海。另有完整男女校服示範圖、清晰導航圖標及重新繪畫的方形臉。`manifest.json` 保存圖片 SHA-256、素材座標、透明輪廓及接合點。

`public/doll.js` 現在只組合這套生成的 PNG 素材；已移除原本以 SVG 路徑畫出的玩偶。圖集原始 PNG 保持完整；建置時依透明輪廓預先裁切，輸出小型 WebP，避免遊玩時下載大圖集、裁切和複製點陣圖。詞卡與按鈕也使用新生成的紙張、布面和木框圖片，文字仍以 HTML 顯示，方便閱讀及觸控。

`public/assets/workshop.png` 是依參考畫風生成的工房背景。

校服與體育服另依使用者提供的實物照片重繪，存於 `painted/uniforms.png`：白襯衫、藍領帶配紅色斜紋、男生藍短褲／女生藍裙、黑皮鞋；體育服為藍色上衣、黃色衣袖和領邊、深色短褲及白波鞋。這四款在角色組合時取代原本的示意服裝。

主頁會先顯示，圖片按需要載入；不等待全部圖集完成才顯示畫面。圖片或程式下載失敗時保留可見的「重新載入」入口，選詞素材失敗時保留之前的外貌及選擇。

主頁只保留遊戲名稱、簡短標題、開始按鈕及兩位穿校服的玩偶。其餘頁面移除頁尾和附加標語，導航使用大圖標。`public/geometry.js` 統一頭身比例、拖放區域及變裝特效位置；長髮先畫在臉後，再疊自然收邊的獨立瀏海，保留臉頰和下巴輪廓。大眼睛採柔和杏仁形，縮小至自然比例、減少露白及高光，圓眼睛採較小正圓形，小眼睛另縮小；長臉使用適度橢圓輪廓，不拉長整個頭部。

所有動態以點陣圖片幀播放，沒有 CSS 動畫或 SVG 動畫：

- 變裝：24 張效果幀預製成一頁 WebP 圖集，與變裝前後的玩偶合成至同一個可重用畫布，30 fps、0.8 秒。
- 完成彩帶：90 張來源圖片縮小並打包成六頁 WebP；先快取壓縮資料，播放時最多解碼兩頁，30 fps、3 秒。
- 實際圖片位於 `public/assets/frames/`，幀規格存於該目錄的 manifest.json。
- 每張特效幀由 `painted/effects.png` 內生成的手繪雲朵、星光、紙片和彩帶組合，幀規格記錄對應素材的 SHA-256。
- 以瀏覽器的第一個動畫幀時間戳作播放起點；快速連點及離開工序時取消舊序列。

重新產生動畫素材：`npm run assets`。此指令需要 Chromium 和 Playwright；在目前雲端環境兩者均已提供。其他環境可安裝 Playwright，並用 CHROMIUM_PATH 指定 Chromium。

檢查角色接合：啟動網站後執行 `node scripts/review-art.mjs`，會輸出新版主頁及九款可選髮型的實際角色對照圖至 `test-results/painted-home.png` 和 `test-results/painted-characters.png`。

## 效能與相容性

`npm run prepare:runtime` 使用 Sharp 保留原畫構圖、透明度和接合座標，產生 `public/assets/runtime/`，並以 esbuild 產生 ES2018 傳統程式包。網站不依賴動態模組、ImageBitmap 或 Image.decode，並支援缺少語音事件 API 的內嵌瀏覽器。發佈時設定 PUBLIC_BASE_URL，令跨網站 HTML 預覽也能找到程式、圖片及語音；語音 URL 依 document.baseURI 組合，支援 about:srcdoc 預覽。圖片以匿名 CORS 載入，確保跨網站預覽可讀取玩偶畫布，不會因畫布污染而在視覺化擷取時失敗。原圖只保留於儲存庫，不複製到公開網站。

初次建置美術約 4.2 MiB，主頁所需圖片約 525 KiB；壓縮報告由建置工具產生。彩帶解碼資料上限約 33 MiB，完成或離開時會釋放；變裝重用畫布，舊玩偶畫布亦會釋放。內容雜湊圖片網址可跨程式更新沿用瀏覽器快取。

`npm run test:performance` 驗證停用點陣圖／解碼／語音事件 API 的情況，並在 1.6 Mbps、150 ms 網路條件下於 iframe 連續完成三輪，檢查傳輸量、動畫解碼上限、錯誤和崩潰。`node tests/preview.test.mjs` 另驗證跨網站 srcdoc 預覽可以完成製作及播放整句粵語。

## 粵語讀音

22 個詞組及 4 個句首片段已生成為香港粵語 MP3，隨網站一同保存，不需要白板預先安裝粵語聲音。全部音訊已通過解碼與時長檢查，發佈版本亦已驗證實際 MP3 播放。

詞卡優先播放 `public/assets/voice/manifest.json` 對應的錄音，缺少錄音時才使用裝置提供的香港粵語聲音（zh-HK／yue）；不以普通話替代。快速改選會取消上一段語音。總結卡右下角有「朗讀句子」按鈕，使用正常語速及去除頭尾冗長留白的獨立錄音，預先載入下一詞組後連續播放兩句完整描述，按性別選擇他／她；播放中點另一個詞或離開頁面會停止。錄音及裝置 TTS 都用同音字「詳詳」明確指定「長長」為 coeng4 coeng4，畫面仍顯示原本詞語。整句的裝置語音備援亦使用正常速率 1。

`node scripts/prepare-summary-audio.mjs` 可用 FFmpeg 從詞卡錄音重新產生 `voice/summary/`；透過保留音高的速度校正恢復正常語速，只裁去頭尾留白。更新詞卡音訊後再執行此工具。

需要重新製作時，使用 `edge-tts==7.3.1` 執行以下指令。製作工具會沿用環境的代理路徑，並將受管理的 CA 加到既有信任鏈，保留 TLS 憑證驗證；網站本身不依賴這個套件、遠端 TTS 或 API key。

```sh
python3 -m pip install --target /tmp/doll-audio-deps edge-tts==7.3.1
PYTHONPATH=/tmp/doll-audio-deps python3 scripts/prepare-cantonese.py
```

## 固定網址與自動更新

GitHub Pages 工作流程在 `.github/workflows/deploy-pages.yml`。每次推送到 `main` 都會先執行完整瀏覽器測試，再建立及部署網站；也可手動執行 workflow。第一次需要在儲存庫 Settings → Pages，選擇 GitHub Actions 作為部署來源。本儲存庫已完成這個一次性設定，固定網址為 https://angusqaq.github.io/PLK-BPII-Game/ 。

`npm run build` 產生分檔網站至忽略的 `dist/`，並以提交 SHA 為程式、樣式、PNG 與音訊加入版本參數，避免更新後沿用舊素材。`dist/version.json` 可用來核對實際部署版本。這不是最終單一 HTML 匯出。

Pages 網址啟用後沿用同一連結；每次更新需等待 GitHub 測試及部署完成，重新整理同一網址即可取得新版。這不是零延遲的即時編輯預覽。

## 驗證

首次安裝測試工具時執行 `npm ci`；啟動網站後執行 `npm test`，共 12 項檢查。使用實際 Chromium 操作完整男女流程、逐項比較外貌圖像、檢查返回修改和快速連點、驗證總結句子、服裝限制及不同尺寸版面，另外以滑鼠及真實觸控事件驗證拖拉後位置固定、錯誤區域不會貼入素材，並核對全部 59 個分層素材及獨立圖片的 PNG 來源及動畫素材雜湊。語音測試明確使用模擬聲音，另測試缺少粵語時不誤用普通話。

截圖存放在忽略的 `test-results/`。測試網址可用 TEST_URL 指定；PLAYWRIGHT_MODULE 和 CHROMIUM_PATH 可指定已安裝的瀏覽器測試工具。
